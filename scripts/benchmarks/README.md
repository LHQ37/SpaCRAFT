# Formal baseline methods

The final comparison methods are INSTINCT, PeakVI, scDREAMER, SEDR, STAligner,
GraphST, and SpaCRAFT.

Reference comparison artifacts are stored under `results/`. Install each
third-party method from its official release in an isolated environment.
Executable wrappers should record the package version, dataset, parameters,
input schema, output schema, and observation ordering.
